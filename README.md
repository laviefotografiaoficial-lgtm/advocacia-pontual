# Advocacia Pontual — site institucional (protótipo)

Protótipo do site da Advocacia Pontual (Família & Sucessões), desenvolvido pela **La Vie Produtora**.

## Como editar os dados
Todos os dados do escritório ficam no bloco `CONFIG`, no início do `<script>` do arquivo `index.html`:
WhatsApp, telefone, e-mail, endereço, horário, OAB, áreas de atuação, equipe e conteúdos.
Itens entre [colchetes] ainda precisam ser fornecidos.

## Antes de publicar oficialmente
- Preencher o número de WhatsApp (formato `55DDDNUMERO`, só números).
- Substituir as fotos demonstrativas pelas fotos da produção La Vie.
- Conectar o formulário a um serviço de envio (ex.: Formspree ou e-mail do escritório).
- Inserir o texto da Política de Privacidade.
- Remover a tag `<meta name="robots" content="noindex, nofollow">` para liberar a indexação no Google.
